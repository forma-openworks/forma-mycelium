# Discord images

Forma Mycelium shows these images in its Discord activity. Discord loads them by URL from this repository.

| File | What it is | Source and license |
|---|---|---|
| `mycelium.png` | The Forma Mycelium logo | Made by `cargo xtask discord-assets` from `assets/logo/mycelium.webp`. Part of this project. |
| `neoforge.png` | NeoForge, shown when the mod is built for NeoForge | `art/discord.png` from [neoforged/.github](https://github.com/neoforged/.github/tree/main/art). © the NeoForged team, art by [Ridanisaurus](https://github.com/Ridanisaurus). Licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changed: scaled 2× without smoothing. |
| `fabric.png` | Fabric, shown when the mod is built for Fabric | `assets/logo.png` from [FabricMC/fabricmc.net](https://github.com/FabricMC/fabricmc.net). Copyright (c) 2016-2022 FabricMC, MIT License (full text below). Changed: scaled 3× without smoothing and centred on a 256×256 transparent canvas. |

The NeoForge and Fabric logos belong to their projects. They appear here only to show which loader a mod uses.

# Картинки для Discord

Forma Mycelium показывает эти картинки в активности Discord. Discord загружает их по ссылке из этого репозитория.

| Файл | Что это | Откуда и лицензия |
|---|---|---|
| `mycelium.png` | Логотип Forma Mycelium | Делает `cargo xtask discord-assets` из `assets/logo/mycelium.webp`. Часть этого проекта. |
| `neoforge.png` | NeoForge — показывается, если мод собирается под NeoForge | `art/discord.png` из [neoforged/.github](https://github.com/neoforged/.github/tree/main/art). © команда NeoForged, рисунок [Ridanisaurus](https://github.com/Ridanisaurus). Лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ru). Изменения: увеличено в 2 раза без сглаживания. |
| `fabric.png` | Fabric — показывается, если мод собирается под Fabric | `assets/logo.png` из [FabricMC/fabricmc.net](https://github.com/FabricMC/fabricmc.net). Copyright (c) 2016-2022 FabricMC, лицензия MIT (полный текст — в английской части выше). Изменения: увеличено в 3 раза без сглаживания и поставлено по центру прозрачного холста 256×256. |

Логотипы NeoForge и Fabric принадлежат их проектам. Здесь они только показывают, под какой загрузчик сделан мод.
